# MOINS UNE

> « Il était moins une. »

**Une série de vidéos courtes générées par IA, avec Seedance 2.5 sur Dreamina.** Un super-héros surgit au pire moment de la journée de quelqu'un, règle sa galère à la dernière seconde, puis disparaît dans une traînée d'or.

| | |
|---|---|
| **Format** | Épisodes d'environ 15 s, vertical 9:16 |
| **Plateformes** | TikTok, Instagram Reels, YouTube Shorts |
| **Ton** | Cool, serviable, spectaculaire. Jamais ridicule |
| **Rendu** | Cinéma réaliste : vraies optiques, caméra qui respire, physique crédible |
| **Règle d'or** | Aucun texte ni chiffre dans les images générées. L'histoire se comprend par l'image seule ; le texte éventuel s'ajoute au montage |
| **Statut** | Préproduction : nom, concept, saison et mise en scène écrits. Photos du héros, costume et prompts Dreamina à venir |
